Kebijakan Privasi (Privacy Policy)

Berlaku efektif sejak: 10 Oktober 2026 | Terakhir diperbarui: 19 Oktober 2026

Selamat datang di Logbook Riset (dapat diakses melalui https://logbookriset.web.id). Kami berkomitmen untuk menjunjung tinggi integritas data akademik dan melindungi privasi serta keamanan seluruh data penelitian mahasiswa, dosen, dan peneliti independen yang menggunakan platform kami.

Dokumen Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda saat menggunakan aplikasi web Logbook Riset.

1. Informasi yang Kami Kumpulkan

Dalam memfasilitasi pencatatan kegiatan riset lapangan dan penyusunan logbook ilmiah terverifikasi, kami mengumpulkan data berikut:

  • Informasi Identitas & Akademik: Nama lengkap, Nomor Induk Mahasiswa (NIM), nama universitas/institusi, program studi, topik skripsi/penelitian, dan nama dosen pembimbing.
  • Data Aktivitas Penelitian: Tanggal, rentang waktu kegiatan (WITA/WIB/WIT), uraian aktivitas lapangan, nama responden/informan kunci, dan luaran (output) kegiatan.
  • Media Dokumentasi Lapangan: Foto bukti kegiatan (yang memuat stempel koordinat GPS Cam), berkas rekaman suara wawancara (audio), dan rekaman video dokumentasi lapangan.
  • Informasi Autentikasi: Alamat email dan tanda pengenal akun aman pengguna melalui Firebase Authentication.

2. Penggunaan Google Drive API & Ketentuan Terbatas (Google User Data Policy)

Logbook Riset memanfaatkan antarmuka pemrograman aplikasi Google Drive API v3 (lingkup: https://www.googleapis.com/auth/drive) untuk mendukung penyimpanan berkas media berukuran besar (rekaman wawancara audio dan video lapangan) secara terstruktur.

Kepatuhan terhadap Kebijakan Data Pengguna Google API:
Akses, penggunaan, penyimpanan, dan transfer informasi yang diterima dari Google API oleh Logbook Riset sepenuhnya mematuhi Google API Services User Data Policy, termasuk ketentuan Penggunaan Terbatas (Limited Use Requirements).

Secara spesifik, penanganan data melalui integrasi Google Drive diatur oleh prinsip-prinsip berikut:

  • Tujuan Terbatas: Google Drive API hanya digunakan untuk membuat folder terstruktur (Logbook_Penelitian_App/User_{id}/...), mengunggah berkas media wawancara riset, dan menghasilkan tautan peninjauan media bagi peneliti pemilik data.
  • Bebas Pelatihan Model AI: Kami TIDAK PERNAH menggunakan berkas audio, video, atau dokumen pengguna yang disimpan di Google Drive untuk melatih model kecerdasan buatan (AI) atau pembelajaran mesin (Machine Learning) umum.
  • Tanpa Penjualan Data: Kami TIDAK PERNAH menjual, menyewakan, atau memperdagangkan data pengguna dari Google Drive kepada pihak ketiga, pialang data (data brokers), atau biro periklanan mana pun.
  • Hak Akses Terisolasi: Setiap pengguna hanya memiliki akses ke folder dan berkas riset miliknya sendiri melalui sistem kontrol akses berbasis UID Firebase.

3. Penyimpanan & Keamanan Data

Kami menerapkan standar keamanan industri untuk menjaga kerahasiaan dan integritas data penelitian Anda:

  • Seluruh komunikasi data dienkripsi saat transit menggunakan protokol HTTPS / TLS 1.3.
  • Basis data penelitian dikelola melalui Google Cloud Firestore dengan aturan keamanan (Security Rules) multi-tenant yang ketat, memastikan tidak ada pertukaran atau pembocoran data antar-pengguna.
  • Aset media riset disimpan secara aman di cloud storage dengan kontrol izin terbatas.

4. Hak Privasi & Kendali Pengguna

Sebagai peneliti dan pemilik data yang sah, Anda memiliki hak penuh untuk:

  • Mengakses, melihat, dan menyunting seluruh catatan logbook yang telah dibuat.
  • Menghapus rekaman media atau catatan riset kapan pun melalui antarmuka aplikasi.
  • Mengekspor seluruh riwayat penelitian ke dalam format dokumen resmi Microsoft Word (.docx).
  • Mengajukan permohonan penghapusan akun dan seluruh berkas data terkait secara permanen.
